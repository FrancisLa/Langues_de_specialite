## Travaux des étudiants

Les travaux produits par les étudiants — notamment leurs corpus, journaux,
scripts, résultats, articles et présentations — ne sont pas automatiquement
placés sous cette licence.

Chaque étudiant ou équipe doit choisir, confirmer ou modifier la licence de
son propre dépôt selon :

- la nature de son code ;
- les droits applicables à ses données ;
- les conditions de réutilisation de ses sources ;
- les contributions des membres de l’équipe ;
- les politiques de l’établissement ;
- les conditions applicables aux documents ou corpus de tiers.

### Suggestion pour les projets étudiants

Lorsqu’un projet contient principalement du code original, des scripts,
des fichiers de configuration et une documentation que l’équipe souhaite
partager largement, la licence **MIT** peut être une option appropriée.

Lorsqu’un projet contient des documents originaux — guides, fiches,
présentations ou documentation pédagogique — l’équipe peut envisager
une licence **CC BY 4.0** pour ces documents.

Toutefois, les étudiants ne doivent pas appliquer une licence à des
données, textes, articles, images ou corpus appartenant à des tiers sans
avoir vérifié qu’ils possèdent le droit de les redistribuer ou de les
sous-licencier.

En cas de doute :

1. conserver le dépôt privé ;
2. ne pas publier les données ;
3. documenter leur provenance et leurs conditions d’accès ;
4. conserver dans Git les scripts, protocoles, inventaires et résultats
   partageables ;
5. demander conseil à l’enseignant ou au service compétent de
   l’établissement.
